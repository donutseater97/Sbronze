## 4.1 Global Fund Filter (Lines 56–66)
- **Purpose:** Centralizes user-selected fund filtering so all app sections share the same filter state unless explicitly overridden.
- **Variables:**
  - `st.session_state.fund_filter`: List[str] — the list of funds currently selected by the user. Initialized at app start (after loading `funds`) to all active funds.
- **Functions/Usage:**
  - The global filter is used by `overview_and_charts()`, `transaction_history()`, and `historical_prices()` to filter displayed funds.
  - Historical charts limit visible options to funds that exist in the historical CSV (`fund_cols`) — when the historical page is used, its reset behavior reinitializes `st.session_state.fund_filter` to `fund_cols`.
- **Implementation notes & UX trade-offs:**
  - Replacing per-section filters (`portfolio_fund_filter`, `trans_fund_filter`, `historical_fund_filter`) with a single `fund_filter` reduces code duplication and ensures a consistent filter across views.
  - This reduces the potential for divergence between sections but removes per-section independent filtering (trade-off between simplicity and per-view flexibility).
  - Widget keys for fund buttons are reused across sections (e.g., `fund_btn_{fund}` and `reset_fund_filters`). This is fine when only one section is visible at a time (common for Streamlit single-page apps). If multiple sections are rendered simultaneously, unique widget keys per section should be used to avoid widget collisions.

## <a name="section-8"></a>8. Overview and Charts (Lines 164–1257)
- **Purpose:** Main dashboard logic for portfolio summary, fund filtering, metrics calculation, and charting.
- **Variables:**
  - `filter_funds`: List of funds selected for filtering.
  - `summary`: DataFrame with per-fund summary statistics.
  - `display_summary`: DataFrame for displaying formatted summary.
  - `raw_values`: DataFrame with raw values for color logic.
  - `fund_qty_decimals_overview`: Dict of decimal precision per fund.
  - `latest_pct_map`, `latest_abs_change_map`, `prev_value_map`: Dicts for price changes.
  - `total_gross`, `total_fees`, `total_net`, `total_quantity`, `total_return`, `total_net_return`: Totals for summary metrics.
  - `total_return_pct`, `total_net_return_pct`, `total_fees_pct`: Calculated percentages for totals.
  - `mom_performance`: Dict of month-over-month performance per fund.
  - `total_market_value`: Total market value of all funds.
- **Functions:**
  - `overview_and_charts()`: Main dashboard function.
  - `format_qty_overview(row)`: Helper for formatting quantity.
  - `style_fund_rows(row)`: Helper for coloring table rows.
  - `_fmt_latest_price_row(row)`, `_fmt_market_value_row(row)`: Helpers for formatting price/market value.
- **Calculations:**
  - Gross Contribution (real): `Quantity * Price (€) + Fees (€)`
  - Gross Contribution (theor): Rounded gross contribution to nearest 10.
  - Net Invested: `Quantity * Price (€)`
  - Average NAV (€): `(Gross Contributions (€) - Fees (€)) / Quantity`
  - Market Value (€): Latest price * Quantity.
  - Total Return (€): `Market Value (€) - Gross Contributions (€)`
  - Total Return (%): `Total Return (€) / Gross Contributions (€) * 100`
  - Net Return (€): `Market Value (€) - Net Invested (€)`
  - Net Return (%): `Net Return (€) / Net Invested (€) * 100`
  - MoM Performance (%): Month-over-month performance per fund, based on recent transactions.
  - Weight (Mkt Value): Proportion of each fund's market value in the total portfolio.
  - Daily P/L (€): Change in portfolio value due to price changes, holding previous day's quantity.
  - Daily P/L (%): Daily P/L as a percentage of previous day's portfolio value.
  - Daily MV (€): Market value of portfolio at each date.
  - Daily MV Δ (€): Change in market value from previous day.
  - Daily MV Δ (%): Percentage change in market value from previous day.
